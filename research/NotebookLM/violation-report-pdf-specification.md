## 1. Document Overview
This document defines the strict layout, contents, and programmatic PDF generation specifications for official **Legal Metrology Violation Reports** under **SIH Problem Statement 2634** [111]. 

Any PDF generated by this system must serve as an admissible legal document in a court of law [93]. It must maintain an immutable link to the database Case ID, incorporate tamper-evident hashes, and embed the mandatory digital signature of the verifying Legal Metrology Officer (LMO) [111].

---

## 2. Structured Layout and Section Order
Every generated PDF report must follow this exact 12-section order [111]:

### 2.1 Cover Block (Header)
* **Visual Layout:** Official Department of Consumer Affairs letterhead, national emblem, and division title [111].
* **Fields:** 
  * Unique Case ID (e.g., `LMD-EC-2026-0091423`) [110, 111].
  * Dynamic QR Code (resolving to the secure state government verification URL) [111].
  * Generation Date and Timestamp [111].
  * Security Classification: `FOR ENFORCEMENT & PROSECUTION ONLY` [111].

### 2.2 Executive Summary
* **Format:** Single, formal paragraph [111].
* **Content:** Identifies the target platform, seller name, SKU description, date of automated detection, and the current enforcement status [110, 111].
* *Example:* "On September 2, 2026, an automated crawl scan flagged the SKU 'Suryoday Premium Masala Biscuits – Family Pack' listed on [Marketplace] by seller Suryoday Foods Pvt. Ltd. The inspection revealed critical labeling non-conformities and pricing violations. The case has been verified by Inspector R. Deshmukh and escalated to SCN dispatch." [110]

### 2.3 Legal Basis
* **Format:** Structured table [111].
* **Content:** Specific central rules and statutory sections invoked, with a concise paraphrase of the legal mandate [111].
* *Example:* "Rule 6(1)(e) - Mandates printed MRP inclusive of all taxes. Rule 6(10) - Mandates digital display of LMPC declarations on e-commerce listings." [110, 111]

### 2.4 Detection Details
* **Content:** Complete metadata tracking of the detection event [111]:
  * Detection Source: `AUTOMATED CRAWLER_NODE_4471` / `CITIZEN_GRIEVANCE` [110, 111].
  * Original URL and Archived URL [110, 111].
  * Crawl Timestamp [110].

### 2.5 Evidence Exhibits
* **Content:** Embeds high-contrast, cropped images [111]. Each exhibit must include [111]:
  * Exhibit Number and Caption [111].
  * Capture Timestamp [111].
  * File SHA-256 Hash [111].
  * Mapped BSA Section 63 Digital Certificate UUID [111].

### 2.6 Field-by-Field Extraction Table
* **Content:** A side-by-side comparative table demonstrating the specific discrepancies detected [21, 111]:

| Field Name | Extracted (E-Commerce Listing) | Extracted (Package Label OCR) | Rule Mapping | Confidence | Status |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Net Quantity** | 120 g | 120 g [57] | Rule 6(1)(c) [140] | 96% [55] | **PASS** [89] |
| **MRP** | ₹950.00 [16] | ₹900.00 [16] | Rule 6(1)(e) [140] | 89% [110] | **FAIL** [110] |
| **Origin** | `NOT_DISPLAYED` [110] | Made in China [110] | Rule 6(1)(a) Proviso [121] | 96% [110] | **FAIL** [110] |
| **Consumer Care** | `NOT_DISPLAYED` | 1800-123-4567 | Rule 6(2) [121] | 99% [110] | **FAIL** [110] |

### 2.7 Inspector Verification & Remarks
* **Content:** Inspector Name, ID, Verification Timestamp [111].
* **Reason to Believe Note:** The mandatory free-text legal justification written by the LMO, documenting their "reason to believe" a violation has occurred under Section 15 of the Act [93, 102, 111].

### 2.8 Offense Classification & Penalty Computation
* **Content:** 
  * Offense Sequence (e.g., `First Offense` or `Second/Subsequent Offense`) retrieved via eMaap lookup [105, 111].
  * Applicable fine band and statutory citation [111].
  * Mapped Section of Act (e.g., `Section 36(1)`) [111, 115].

### 2.9 Enforcement Action Log
* **Content:** Audit log of notices sent, statutory response countdowns, and recipient read-receipt timestamps [111].

### 2.10 Officer Determination & Signature Block
* **Content:** Clear signature zone displaying [111]:
  * Digital Signature / Digital Signature Certificate (DSC) marker [111].
  * Officer Rank and circle jurisdiction [111].
  * Date [111].

### 2.11 Annexures
* **Content:** Appends raw JSON metadata, system configuration parameters, and links to public databases [111].

### 2.12 Audit Trail Footer
* **Content:** Appended to every page:
  * Document SHA-256 Hash [111].
  * Generation timestamp [111].
  * Standard system disclaimer: "This document is system-generated and certified under Section 63, BSA 2023. Authenticate using the QR code." [111]

## 3. PDF Generation Implementation (Python `fpdf2` Engine)
Developers must use the following programmatic PDF layout and font parameters to build the report generator in Python:

### 3.1 Design Principles
* **Color Palette:** Professional, government-style (Deep Navy primary, Slate Blue secondary, Off-Black body, Light Gray table backgrounds). No decorative CSS or HTML styles [html_restriction].
* **Fonts:** Use standard Helvetica/Arial family. In bilingual reports, embed Devanagari TrueType fonts (e.g., `Lohit-Devanagari.ttf`) to ensure Hindi text renders perfectly without glyph clipping [63, pdf-creation].
* **No Executable Code:** The output must be static and print-ready [Security - Generated Documents].

### 3.2 Dynamic Python Script (`generate_pdf_report.py`)
This script must be saved to `/workspace/scratch/` and run when an LMO confirms a violation [data-craft, pdf-creation].

```python
import datetime
import hashlib
from fpdf import FPDF

class LMDViolationReport(FPDF):
    def header(self):
        # Top Header Letterhead
        self.set_font('Helvetica', 'B', 14)
        self.set_text_color(10, 30, 80) # Deep Navy
        self.cell(0, 8, "GOVERNMENT OF INDIA", ln=1, align="C")
        self.set_font('Helvetica', 'B', 10)
        self.cell(0, 6, "DEPARTMENT OF CONSUMER AFFAIRS - LEGAL METROLOGY DIVISION", ln=1, align="C")
        self.set_draw_color(10, 30, 80)
        self.set_line_width(0.5)
        self.line(10, 25, 200, 25)
        self.ln(5)

    def footer(self):
        # Audit Trail Footer on every page
        self.set_y(-15)
        self.set_font('Helvetica', 'I', 8)
        self.set_text_color(100, 100, 100)
        disclaimer = "This document is system-generated and certified under Section 63, BSA 2023. Verify via QR code."
        self.cell(0, 10, f"{disclaimer}  |  Page {self.page_no()}", align="C")

def build_pdf_report(data, output_path):
    pdf = LMDViolationReport()
    pdf.add_page()
    pdf.set_margins(10, 10, 10)
    pdf.set_auto_page_break(auto=True, margin=15)
    
    # 1. Cover Block Meta
    pdf.ln(5)
    pdf.set_font('Helvetica', 'B', 11)
    pdf.set_text_color(200, 30, 30) # Red warning
    pdf.cell(0, 6, "SECURITY CLASSIFICATION: FOR ENFORCEMENT & PROSECUTION ONLY", ln=1)
    pdf.set_text_color(0, 0, 0)
    
    pdf.set_font('Helvetica', 'B', 10)
    pdf.cell(100, 6, f"CASE ID: {data['case_id']}", ln=0)
    pdf.cell(0, 6, f"GENERATED AT: {data['generated_at']}", ln=1, align="R")
    pdf.ln(4)
    
    # 2. Executive Summary
    pdf.set_font('Helvetica', 'B', 11)
    pdf.set_text_color(10, 30, 80)
    pdf.cell(0, 6, "2. Executive Summary", ln=1)
    pdf.set_font('Helvetica', '', 9.5)
    pdf.set_text_color(30, 30, 30)
    summary_text = (
        f"An automated LMPC compliance scan on {data['crawl_date']} flagged critical violations "
        f"on the e-commerce listing {data['listing_url']} by seller {data['seller_name']}. "
        f"The case was reviewed and verified by human inspector {data['inspector_name']} "
        f"(ID: {data['inspector_id']}) on {data['verified_date']}."
    )
    pdf.multi_cell(0, 5, summary_text)
    pdf.ln(4)
    
    # 3. Legal Basis
    pdf.set_font('Helvetica', 'B', 11)
    pdf.set_text_color(10, 30, 80)
    pdf.cell(0, 6, "3. Legal Basis", ln=1)
    pdf.set_font('Helvetica', '', 9)
    pdf.set_text_color(30, 30, 30)
    for rule in data['legal_basis']:
        pdf.multi_cell(0, 4.5, f"- {rule['rule_id']}: {rule['paraphrase']}")
    pdf.ln(4)

    # 4. Field-by-Field Extraction Table
    pdf.set_font('Helvetica', 'B', 11)
    pdf.set_text_color(10, 30, 80)
    pdf.cell(0, 6, "4. Compliance Discrepancy Findings Table", ln=1)
    pdf.ln(2)
    
    # Table Header
    pdf.set_font('Helvetica', 'B', 9)
    pdf.set_fill_color(230, 235, 245)
    pdf.cell(40, 6, "Field Name", border=1, fill=True)
    pdf.cell(50, 6, "Listing Value", border=1, fill=True)
    pdf.cell(50, 6, "Package Label OCR", border=1, fill=True)
    pdf.cell(25, 6, "Confidence", border=1, fill=True)
    pdf.cell(25, 6, "Status", border=1, fill=True, ln=1)
    
    # Table Body
    pdf.set_font('Helvetica', '', 8.5)
    for field in data['fields']:
        pdf.cell(40, 6, field['name'], border=1)
        pdf.cell(50, 6, field['listing_val'], border=1)
        pdf.cell(50, 6, field['label_val'], border=1)
        pdf.cell(25, 6, f"{field['confidence']}%", border=1)
        if field['status'] == "FAIL":
            pdf.set_text_color(200, 30, 30) # Red
        else:
            pdf.set_text_color(30, 120, 30) # Green
        pdf.cell(25, 6, field['status'], border=1, ln=1)
        pdf.set_text_color(0, 0, 0)
    pdf.ln(4)
    
    # 5. Inspector Remarks (Reason to Believe)
    pdf.set_font('Helvetica', 'B', 11)
    pdf.set_text_color(10, 30, 80)
    pdf.cell(0, 6, "5. Inspector Verification & 'Reasons to Believe'", ln=1)
    pdf.set_font('Helvetica', 'B', 9)
    pdf.cell(0, 5, f"Officer: {data['inspector_name']}  |  Jurisdiction: {data['inspector_jurisdiction']}", ln=1)
    pdf.set_font('Helvetica', 'I', 9)
    pdf.set_text_color(50, 50, 50)
    pdf.multi_cell(0, 5, f"\"Reason to Believe Note: {data['reason_to_believe_note']}\"")
    pdf.ln(5)
    
    # 6. Offense Classification & Penalties
    pdf.set_font('Helvetica', 'B', 11)
    pdf.set_text_color(10, 30, 80)
    pdf.cell(0, 6, "6. Offense Classification & Penalty Computation", ln=1)
    pdf.set_font('Helvetica', '', 9.5)
    pdf.set_text_color(30, 30, 30)
    offense_text = (
        f"Offense Sequence: {data['offense_seq']} (retrieved from eMaap Registry)\n"
        f"Statutory Section: {data['statutory_section']}\n"
        f"Suggested Compounding Penalty: INR {data['fine_amount']}/-\n"
        f"Discharging Officer: State Controller of Legal Metrology"
    )
    pdf.multi_cell(0, 5, offense_text)
    pdf.ln(10)
    
    # 7. Signature Block
    pdf.set_font('Helvetica', 'B', 10)
    pdf.cell(100, 5, "Inspector Signature Zone:", ln=0)
    pdf.cell(0, 5, "Approving Controller Signature Zone:", ln=1, align="R")
    pdf.ln(12)
    pdf.cell(100, 5, "[DIGITALLY SIGNED VIA DSC]", ln=0)
    pdf.cell(0, 5, "P_CONTROLLER_APPROVED_E_SIGN", ln=1, align="R")
    
    # Save PDF
    pdf.output(output_path)
    print(f"Successfully generated PDF report at: {output_path}")
```
